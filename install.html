ИНСТРУКЦИЯ

01

Установка игры

Для игры необходима оригинальная версия Mafia II (Classic).
Рекомендуем использовать один из вариантов ниже:

СКАЧАТЬ ИГРУ (вариант 1) СКАЧАТЬ ИГРУ (вариант 2)
!

Путь установки игры должен быть БЕЗ пробелов и русских букв.

02

Загрузка лаунчера

Скачайте актуальную версию лаунчера для получения последних обновлений.

СКАЧАТЬ ЛАУНЧЕР
03

Установка лаунчера

Откройте скачанный архив и запустите единственный файл. Следуйте инструкции по установке.

04

Запуск лаунчера

Запустите лаунчер с ярлыка Mafia 2 NCRP на рабочем столе.

05

Старт игры

Перейдите в настройки (нажав на шестерёнку в правом верхнем углу) и укажите ваш будущий логин. Это НЕ имя персонажа. Запомните его!

Нажмите кнопку Играть

!

При возникновении проблем обратитесь к нам в Discord или найдите свою проблему на этой странице
